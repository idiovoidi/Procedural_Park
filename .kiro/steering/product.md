# AI Snap - Product Overview

AI Snap is a 3D wildlife photography game where players explore a procedurally generated safari park, observe creatures in their natural habitat, and capture stunning photos. The game features peer-to-peer multiplayer support for shared exploration experiences.

## Core Features

- **Procedural Wildlife**: 60+ unique creatures with varied anatomies, behaviors, and rarities generated using seeded randomization
- **Photography System**: Score-based creature photography with distance, framing, and rarity calculations
- **Dual Camera Modes**: Ride mode (automated path) and free roam mode (WASD controls)
- **Advanced Visual Effects**: CRT simulation, film grain, chromatic aberration, and retro pixel-art styles
- **Multiplayer**: Serverless peer-to-peer WebRTC connections for real-time co-exploration
- **Biome System**: Multiple ecosystems including forest, meadow, rocky, wetland, crystal cave, and floating islands
- **Video Recording**: Built-in screen recording capability (30s max)

## Target Platform

Modern web browsers with WebGL 2.0 support. Designed for static hosting (GitHub Pages, Vercel, Netlify) without server requirements.
