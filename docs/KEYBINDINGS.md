# AI Snap - Key Bindings

## Camera Controls
- **W** - Move forward
- **S** - Move backward
- **A** - Move left
- **D** - Move right
- **Shift** - Sprint
- **Space** - Jump
- **C** - Toggle camera mode (Ride/Free Roam)
- **Arrow Keys** - Look around

## Game Actions
- **F** - Take photo
- **R** - Restart ride
- **P** - Pause/Resume
- **+/=** - Speed up
- **-/_** - Speed down
- **X** - Randomize creature

## UI Actions
- **G** - Toggle gallery
- **M** - Toggle multiplayer panel
- **H** - Toggle shortcuts help
- **Escape** - Toggle settings
- **N** - Toggle day/night mode

## Shader Controls
- **V** - Toggle shader effects
- **[** - Decrease threshold
- **]** - Increase threshold
- **{** - Decrease intensity
- **}** - Increase intensity

## Video Recording
- **;** - Toggle video recording (30s max)

## Notes
- Most controls only work in "game" context (not in menus)
- Camera movement only works in Free Roam mode
- Photos can only be taken when the game is playing (not paused)
